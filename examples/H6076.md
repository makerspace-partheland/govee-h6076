# Deutsch

## Konfiguration

1. [h6076.de.yaml](h6076.de.yaml) in das ESPHome-Konfigurationsverzeichnis als `govee-h6076.yaml` kopieren.
2. In `secrets.yaml` die Werte für `wifi_ssid`, `wifi_password` und `api_encryption_key` eintragen. Die [ESPHome-API-Seite](https://esphome.io/components/api/#configuration-variables) erzeugt einen gültigen API-Schlüssel.

Die Vorlage lädt die Komponente über `external_components` aus dem GitHub-Repository.

Anschließend im Device Builder **Validate** wählen und nach der [Flashanleitung](../docs/installation.md#deutsch) installieren.

## Anzeigenamen

Der Anzeigename des Geräts steht unter `esphome.friendly_name`. Für Lampe und Regler die `name`-Einträge unter `light`, `sleep_timer` und `music_sensitivity` ändern. Effektnamen stehen jeweils unter `name` in `effects`.

## Hardwareeinstellungen

Die Vorlage verwendet `variant: ESP32C3`, `flash_size: 4MB` und ESP-IDF für den ESP8685. Die Verbindung zum FR8018HD nutzt GPIO19 als TX und GPIO18 als RX bei 115200 Baud, 8N1. Die USB-Konsole bleibt deaktiviert, weil sie dieselben Pins belegt.

## Bluetooth-Proxy

- Passiver BLE-Empfang: bereits im Alltag getestet.

## Anpassungen in der YAML

- Unter `light.music_palette` die sieben RGB-Farben für die Musikmodi ändern.
- Bei `govee_h6076_scene` unter `effects` den Wert von `scene` ändern. Beispiele sind `rainbow`, `fireworks` und `meteor`.
- Beim Effekt `govee_h6076_segments` unter `segments` die Werte `color` und `brightness` für die sieben Segmente ändern. `brightness` liegt zwischen 0 und 100.
- `music_sensitivity.initial_value` legt den Anfangswert der Musikempfindlichkeit fest. Ein zuvor gespeicherter Reglerwert hat Vorrang.
- Für einen Betrieb ohne Bluetooth-Proxy die Blöcke `bluetooth_proxy` und `esp32_ble_tracker` entfernen.

## Bedienung in Home Assistant

Der Regler „Musikempfindlichkeit“ stellt die Empfindlichkeit von 0–99 ein. Änderungen werden auf dem ESP gespeichert.

Der Regler „Schlafmodus“ startet den Timer mit 10–240 ganzen Minuten; 0 beendet ihn. Die Lampe muss eingeschaltet sein und mindestens 10 % Helligkeit haben. Die Uhrzeit muss von Home Assistant synchronisiert sein.

# English

## Configuration

1. Copy [h6076.en.yaml](h6076.en.yaml) into the ESPHome configuration directory as `govee-h6076.yaml`.
2. Set `wifi_ssid`, `wifi_password` and `api_encryption_key` in `secrets.yaml`. The [ESPHome API page](https://esphome.io/components/api/#configuration-variables) generates a valid API key.

The template loads the component from the GitHub repository through `external_components`.

Select **Validate** in Device Builder, then follow the [flashing guide](../docs/installation.md#english).

## Display names

The display name of the device is defined by `esphome.friendly_name`. For the light and its controls, adjust the `name` entries under `light`, `sleep_timer` and `music_sensitivity`. The effect names are defined by `name` in each entry under `effects`.

## Hardware settings

The template uses `variant: ESP32C3`, `flash_size: 4MB` and ESP-IDF for the ESP8685. The connection to the FR8018HD uses GPIO19 for TX and GPIO18 for RX at 115200 baud, 8N1. The USB console is disabled because it occupies the same pins.

## Bluetooth proxy

- Passive BLE reception: already tested in daily use.

## YAML adjustments

- Adjust the seven RGB colors for music modes under `light.music_palette`.
- Set `scene` in the `govee_h6076_scene` entry under `effects`. Examples include `rainbow`, `fireworks` and `meteor`.
- Within the `govee_h6076_segments` effect, set `color` and `brightness` for the seven entries under `segments`. The range for `brightness` is 0–100.
- `music_sensitivity.initial_value` defines the starting music sensitivity. A previously stored control value takes precedence.
- To run without the Bluetooth proxy, delete the `bluetooth_proxy` and `esp32_ble_tracker` blocks.

## Controls in Home Assistant

The “Music sensitivity” control adjusts sensitivity from 0–99. Changes are stored on the ESP.

The “Sleep mode” control starts the timer with 10–240 whole minutes; 0 cancels it. The lamp must be on with at least 10% brightness. Its clock must be synchronized from Home Assistant.
